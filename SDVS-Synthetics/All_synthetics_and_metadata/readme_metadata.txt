readme_metadata

Metadata files: 

site_info.txt
Site information file
Line 1 is a header describing Line 3
Line 2 is a header describing the data columns
Line 3 is a header with the number of stations
Lines 4 to end have columns: 
	Col 1: stN: station number 
	Col 2: epi_dist_km: station epicentral distance in km

catalog_info.txt
Earthquake catalog information
Line 1 is a header describing line 3. 
Line 2 is a header describing the data columns.
Line 3 is a header with the number of earthquakes
Line 4 to end of block have columns: 
	Col 1: evN: Event number
	Col 2: lmo: log10 seismic moment, Nm
	Col 3: Mw: moment magnitude as: Mw=(log10(Mo) - 9.05)/1.5
